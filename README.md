# CodexLink 电脑控制台

双击本文件夹的 **控制台.cmd**。手机连接地址可在控制台查看，使用自己的固定域名或临时外网地址。

## 0.9.1：特权手机只读查看其他手机的仅聊天会话

电脑后台更新至 0.9.1 后，先在控制台停止并重新启动手机连接。普通手机可以继续使用 **0.9.0，不强制升级、不重新批准设备**；只有需要新查看入口的手机覆盖安装 **CodexLink-0.9.1.apk**（versionCode 14）。数学公式排版继续保留。

电脑进入 **设置与手机审批 → 1 审批 / 撤销手机 / 设置手机项目范围**，选中已批准的特权手机，输入 **V → 1 → Y** 开启只读查看。默认关闭；输入 V → 2 → Y 关闭，无需再次重启后台。

0.9.1 特权手机在聊天列表切换 **其他手机 · 只读**，可按聊天名称或手机名称搜索，查看历史与题目图片，并显示归属名称和设备标识后八位以区分同名手机。只列其他已批准、当前处于仅聊天模式且属于当前账号代次的手机会话；不展示电脑编程会话。查看端可以处于普通或仅聊天模式。

只读页不提供发送、停止任务、回答提问、改名、删除、接管或交回入口，后台也拒绝这些操作。会话页定时读取最新记录，列表可点刷新更新；不订阅对方的控制事件。关闭查看权限后，手机收到通知或下次状态检查时清空查看页及图片缓存；已复制或保存的内容无法远程收回。源手机被撤销或切出仅聊天模式后，其会话不再允许读取。

原有 `/api/threads`、图片与任务接口继续按本机权限工作；新增查看接口独立授权。0.9.0 手机即使获授权，也继续使用自己的原列表，需要升级才有新入口。更新不扩大任何手机的电脑操作权限。详细接口见 [API.md](API.md)。

## 每台手机仅聊天模式（0.8.0）

1. 首次更新仅聊天后台时停止并重新启动电脑连接，新安装可使用当前随附的 **CodexLink-0.9.1.apk**；已有 0.9.0 手机可继续使用。
2. 电脑控制台进入 **设置与手机审批 → 7**，选择手机，选 **3 仅聊天（允许联网）**；也可在设备管理中选手机后输入 **E**。
3. 手机刷新后显示“仅聊天”，只列出本设备独立聊天，点“新建”即可聊天、联网和发题目图片。不选择电脑目录，不提供文件附件、电脑操作、审批放行或桌面接管。

切换前先停止或等待该手机正在运行的任务结束。切换会取消旧模式排队任务，并清空手机旧视图、草稿和重试记录；其他手机保持原设置。切回普通模式后恢复原项目范围，独立聊天保留在仅聊天模式中。详细边界与验收见 [CHAT_ONLY.md](CHAT_ONLY.md)。**仅聊天后台测试.cmd** 仍保留作为电脑本地试验入口。

## 退出电脑端并接管原会话（0.7.0 试用）

1. 更新后台后先停止并重新启动电脑连接，新安装可使用当前随附的 `CodexLink-0.9.1.apk`；已有 0.9.0 手机可继续使用。
2. 在 **设置与手机审批 → 1** 中选择你自己的手机，输入 **T**，开启“退出电脑端并接管”权限。默认对所有手机关闭；只给信任的手机开启。
3. 手机打开原聊天，点 **接管会话**。空闲时直接接管；电脑仍占用时会先检查，并显示“退出电脑端并接管”确认框。
4. 确认后后台请求整个桌面 Codex 正常退出，等待其进程与后台释放，再恢复同一个会话 ID。手机查看进度和结果后自行继续发送，不会复制聊天或自动重发原任务。

**托盘退出修正**：最初试用版仅关闭窗口，Codex 会继续留在托盘，导致接管失败。现在改为恢复并校验桌面窗口，发送菜单“退出 ChatGPT / Codex”对应的 **Ctrl+Q**，然后等待桌面进程及其 app-server 退出。本次只更新电脑后台，停止并重新启动连接即可，手机不用重新安装。需要 Windows 保持登录且未锁屏；锁屏、焦点无法确认、权限不一致或退出超时均明确报告失败。操作会短暂激活 Codex 窗口，不自动强杀。

此版本识别当前 Windows 用户、同一图形登录会话中的 Windows 商店版 `OpenAI.Codex`。通过安装包路径、进程启动时间和父子关系校验，保护独立手机后台与其 Codex 子进程。不按程序名批量杀进程，不删除会话锁，不自动强制结束桌面端。若进程变化、窗口不能正常关闭、退出超时或占用来自其他 CLI，会报告失败；这不是仅转交单个会话的无感切换。

**退出桌面端可能中断它的所有会话任务，未保存草稿也可能受影响；已经完成的文件修改不会撤销。** 确认关闭手机也不会取消已确认的后台操作。确认凭据绑定手机身份、账号代次和原会话，60 秒后过期；重复确认不会再次退出桌面端。后台重启不重放旧接管，响应丢失时查询原操作状态。

已做真实环境的只读进程识别，以及使用模拟退出控制器的自动化测试；用户发现旧关闭窗口方案不能退出托盘后台，改为 Ctrl+Q 后已确认接管成功。原来的“交回电脑”在普通模式保留；仅聊天不提供桌面接管。每手机审批和目录权限继续执行。

## 每台手机的操作审批（0.6.0）

升级后先停止并重新启动电脑连接。进入 **设置与手机审批 → 7 设置手机操作审批**，选择手机，再选择 **1 手动审批** 或 **2 帮我批准**。也可在设备管理中输入 **E**；批准手机时也能设置。手机的“连接”窗口显示本机的新任务审批方式，任务卡片显示该任务实际采用的方式。

- 设置绑定设备公钥和账号代次，重新登录、重启后台后保留。已有设备首次升级继承原全局审批方式，以后互不影响。
- 审批方式在消息被后台接受时保存。修改后对新消息、新建聊天生效；已经提交、排队、运行、等待审批及使用原消息编号重试的任务保留原设置。
- 同一聊天中不同手机轮流提交时，每条任务显式指定审批方式和按需审批策略，避免沿用上一台手机的设置。新建聊天仍使用 `workspace-write`，已有聊天不改文件或联网边界。
- 手动审批、自动审查回退到人工的请求，以及需要回答的问题，只发送给原提交手机；其他手机即使能访问同一项目，也不能代为回答。
- 设置立即保存并通知对应手机，不需要重新登录。菜单 **8 设置新手机默认审批** 仅影响尚未初始化的设备，不修改已配置手机。

“帮我批准”仍是官方自动审查，可能拒绝或要求人工处理，不会代答问题。0.8.0 每手机仅聊天的第三选项见上文；数学公式排版由 Android 0.9.0 支持。

## 每台手机的项目范围（0.5.0）

更新电脑源码后，先在控制台停止并重新启动连接，再使用新菜单。操作位置：**设置与手机审批 → 1 审批 / 撤销手机 / 设置手机项目范围**，选择手机后输入 **P** 修改范围；输入 **A** 批准手机时也可以设置。

- **指定目录**：每行输入一个完整目录，支持一个或多个，空行结束；允许访问这些目录及其子目录的聊天。
- **所有目录**：不按聊天项目目录过滤，可查看其他项目聊天；Android 0.5.0 新建聊天时可填写电脑上已存在的项目路径。
- 范围绑定设备公钥身份，同一台手机重新登录保持原配置。旧手机首次升级沿用原有后台项目范围；未单独配置的新手机默认沿用默认项目目录，不会自动获得所有目录。
- 修改已登录手机的范围后，后台会断开其实时连接使其刷新，无需重启后台。Android 0.5.0 会清除旧列表、当前聊天显示和内存图片缓存。
- 如果该手机还有新范围外的任务正在执行，保存会被拒绝，请先停止任务或等待完成；新范围外的排队任务会取消。重启恢复的排队任务在执行前再次检查提交手机的当前范围；旧版本没有设备归属的排队任务转为需要检查，不自动执行。
- 目录检查覆盖聊天列表、搜索所用分页、历史、发送、接管、任务、授权响应、附件和实时事件重放。手机只能管理自己的登录连接，其他手机在电脑端管理。

这里控制的是**项目和聊天访问范围**，不等同于限制模型实际读写文件的沙箱。每手机审批见上方 0.6.0 说明；0.8.0 起仅聊天可禁止电脑工具，见上方说明。已经在手机上看过、复制或保存在草稿中的内容不会被远程抹除。旧客户端仍受后台检查，建议安装最新版以正确展示范围、审批方式和清理旧界面。

## 日常使用

- **1 启动手机连接**：依次启动电脑后台和外网隧道，自动使用已保存的项目目录。重复选择会复用已运行的服务。
- **2 查看状态与连接地址**：显示后台、外网状态及手机地址，并检查外网能否到达本机后台。
- **3 停止手机连接**：先关闭外网，再停止后台；会中断手机任务。
- **0 退出窗口**：只退出控制台，已启动的后台和外网继续运行。直接关闭窗口也一样。

开启开机自动启动后，登录当前 Windows 用户，电脑后台和外网会在隐藏窗口中依次启动，登录后先等待约 15 秒；启动失败后等待 60 秒再试，不限次数，直到成功或手动停止。等待期间通过定时器休眠，不持续执行检查。无需打开桌面 Codex 或控制台。电脑需保持开机联网，避免休眠。

## 设置与手机审批

主菜单选 **4 设置与手机审批**：

1. **审批 / 撤销手机**：手机首次登录后，选对应设备，目视核对两端核对码一致，输入 A 批准；R 撤销。无需重新输入核对码。
2. **设置账号密码**：密码至少 8 个字符。修改后，手机需要重新登录和批准；聊天记录保留。
3. **设置固定外网**：在本地粘贴 Cloudflare 提供的完整连接命令；输入隐藏，隧道凭据由当前 Windows 用户加密保存。Cloudflare 的域名路由仍需指向本机后台。
4. **修改默认项目目录**：下次停止并重新启动连接后生效，用于新手机的初始范围和所有目录模式的新建聊天默认位置；已配置手机的范围保持不变。
5. **开启 / 关闭开机自动启动**：设置当前 Windows 用户登录后自动启动后台和外网。关闭自启不会停止已经运行的连接；主菜单“停止手机连接”会取消本次尚未完成的自动重试，但下次登录仍会按自启设置运行。
6. **修改电脑附件目录**：设置手机上传普通文件的电脑保存位置。
7. **设置手机操作审批**：选择设备后设置手动审批或“帮我批准”，已提交任务保持原设置。
8. **设置新手机默认审批**：只作为尚未初始化的设备的默认值，已配置设备不变。

## 文件与数据

原来的单独 CMD 入口已经收进 **旧版入口** 文件夹，仍可用于单独管理后台或外网。日常只需控制台。

账号、聊天状态、手机批准记录、隧道凭据及控制台设置保存在当前用户的本地数据目录，与程序文件夹分开。移动程序文件夹前，先在控制台停止手机连接；移动或改名后在新位置打开一次控制台；已开启的开机自启会自动更新到当前位置，然后可启动连接。已关闭的自启会保持关闭。

本次只整理电脑操作入口，手机 APK 和已经配置的账号、设备安全与固定隧道继续使用。

接口说明见 API.md，设备安全说明见 DEVICE_SECURITY.md。

## 历史图片预览（0.3.1）

手机上传的图片在聊天中显示缩略图，点击查看大图，支持双指缩放、拖动和双击还原；刷新或重新打开聊天后会通过设备签名认证从电脑加载。原图已删除时显示不可用提示。电脑后台也需更新至 0.3.1。

## 普通文件附件（0.4.0）

- 在聊天中点“＋ 文件”，从系统选择器选择文件；每个文件最多 10 MB，每条消息的图片与文件合计最多 8 个。
- QQ / 微信的“其他应用打开”或系统分享中选择掌上 Codex，接收后选择新建或已有聊天。文件先进入草稿，点击发送才上传电脑并交给 Codex。
- 导入文件先存手机应用私有目录，未登录时也会暂存，登录后再选择聊天。正常发送失败时保留文件和消息编号供重试。
- 电脑附件目录由本机配置保存，控制台“设置与手机审批 → 6 修改电脑附件目录”可调整；重启连接后对新上传生效，已有文件保留原位置。
- 文件卡片保留文件名和大小；普通文档由 Codex 在电脑端读取处理，手机端暂不提供文档预览或下载。
- 附件目录包含用户文件，不应上传 GitHub；本机目录配置也由 .gitignore 排除。

## 帮我批准

后台通过本机 Codex app-server 的 `approvalsReviewer: "auto_review"` 和 `approvalPolicy: "on-request"` 接入官方自动审查，使用现有 Codex 登录，无需单独 API Key。新建聊天仍使用 `workspace-write`；继续聊天时保留其原有文件和联网边界。自动审查会决定允许或拒绝权限申请，不保证全部放行，也不会代答任务中的用户问题；需要人工处理的请求仍显示在手机。

新手机默认手动审批。默认值保存在 `%LOCALAPPDATA%\CodexPhoneBridge\execution-settings.json`；每手机设置和任务审批快照保存在原 `bridge.sqlite` 中，与桌面 Codex 全局配置分开，开机启动后继续有效。0.6.0 起修改默认值不会改变已有设备。运行数据不应提交 Git。

官方说明：[Codex Auto-review](https://learn.chatgpt.com/docs/sandboxing/auto-review)。
